# Indicadores COINSU

Tablero mensual de indicadores del Sistema de Gestión de Calidad de COINSU,
publicado con GitHub Pages para poder compartirlo por enlace.

- `index.html` — el tablero (una sola página, sin dependencias salvo Google Fonts)
- `og.png` — portada que usan las vistas previas de enlace (WhatsApp, etc.)
- `robots.txt` — la página no se indexa en buscadores

Edición actual: **julio 2026**. Se genera desde los libros maestros O-GR-02 y
O-GR-05 y las fichas F-GR-05 del mes.
